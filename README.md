# Belajar Matematika Kelas 2

Situs belajar online untuk melengkapi pelajaran Matematika murid SD kelas 2.

Alamat situs: https://i-rokhim.github.io/belajar_matematika/

## Jenjang dan mapel

SD kelas 2, Matematika (percontohan).

## Topik

- Bilangan sampai 1.000 (segera hadir)
- Penjumlahan dan pengurangan (sudah ada)
- Pengukuran (segera hadir)
- Bentuk di sekitar kita (segera hadir)
- Posisi benda dan pola (segera hadir, opsional)

## Cara memperbarui situs

1. Ubah berkas di VS Code, lalu simpan lewat File, Save All.
2. Di Command Prompt, masuk ke folder proyek: cd /d C:\belajar_matematika
3. Jalankan: git add .
4. Jalankan: git commit -m "pesan singkat tentang perubahan"
5. Jalankan: git push
6. Tunggu 1 sampai 2 menit, lalu buka situs dan tekan Ctrl+F5.

Jangan menyimpan data murid, password, atau token di repository ini (repository publik).
